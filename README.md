## Descripción

La Plataforma Académica Básica de proyecto sencillo creado para practicar el uso de Git y GitHub colaborativo.

El proyecto permite mostrar información básica de una institución educativa, como cursos, horarios y noticias académicas.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub
